# 🏷 guessing_game

 A simple Bash terminal games that challenges players to guess a rondomly generated number using hints and feedback.

## 📌 Problem Statement

The Guessing Game helps beginners learn programming fundamentals through an interactive game. it practices user input, conditional statments, loops, variable, and random number generation using Bash scripting.

## 🎯 Project Goals

- Generate a random number.
- Allow players to enter guesses.
- Tell players whether thier guess is too high or too low.
- Count the number of attempts.
- Congratulate the player when they guess correctly.

## 🛠 Tech Stack

- Language: Bash
- Operating System: Linux
- Tools: VS Code, Git, GitHub, Linux Terminal
